# STiS email signature assets

Public image assets for the STiS email signature: the logo and four social icons. They are hosted here so email clients can load them over HTTPS.

## Files

| File | Purpose |
|---|---|
| `stis-logo.png` | STiS logo, 1200 px, white letters |
| `stis-logo.svg` | Vector logo |
| `signature-template.html` | HTML signature template with placeholders instead of personal data |
| `icon-telegram.png` | Telegram icon, 48 px |
| `icon-max.png` | MAX icon, 48 px |
| `icon-vk.png` | VK icon, 48 px |
| `icon-youtube.png` | YouTube icon, 48 px |

## Signature template

`signature-template.html` is the full HTML signature with placeholder name, role, phones and email. Replace them with the employee data and paste into Gmail, Outlook or Apple Mail. Images already point to GitHub Pages.

## Note

This is a working fallback for the email signature. For a corporate rollout, the same files should be moved to the company site (`stis.ru`) and the URLs in the signature HTML updated.

No personal contact data is stored in this repository.
